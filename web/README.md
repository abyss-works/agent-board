# agent-board-web

agent-board REST API를 브라우저에서 쓰는 웹 클라이언트다. 현황, 보드, 이슈 목록과 상세, 활동, 마일스톤을 보고 이슈 등록·수정·상태 변경·댓글과 프로젝트·마일스톤 생성·수정을 한다. 행위자는 사용자 `owner`다.

React 19 + TypeScript, Vite로 빌드하는 SPA다. Tailwind CSS 4, shadcn/ui 구성(radix-ui), TanStack Query, react-router, dnd-kit, react-markdown을 쓴다. 서버 쪽 중계는 없다.

## 실행

Node 22와 pnpm이 필요하다.

```bash
pnpm install
pnpm dev        # http://127.0.0.1:5173
```

개발 서버는 세 인스턴스를 같은 출처로 프록시한다. 프록시는 경로만 넘기고 토큰이나 헤더를 넣지 않는다.

| 화면의 인스턴스 | 브라우저 경로 | 대상 |
|---|---|---|
| 기록용 | `/api/local/v1/...` | `http://127.0.0.1:8420` |
| 스테이징 | `/api/staging/v1/...` | `http://127.0.0.1:8421` |
| 운영 | `/api/prod/v1/...` | `https://agb.abyssworks.dev` |

운영 빌드(`pnpm build`, 결과는 `dist/`)는 같은 출처의 `/v1`을 부르는 인스턴스 하나로 동작한다. 서버는 환경변수 `AGB_WEB_DIR`로 지정한 폴더의 이 결과를 `/v1` 밖의 경로에서 서빙한다. 배포 구성은 저장소의 `deploy/`에 있다.

## 로그인

1. 로그인 화면에서 인스턴스를 고른다. 화면 아래에 `/v1/health` 결과로 서버가 켜져 있는지 보인다.
2. 서버의 `AGB_TOKEN` 값을 붙여 넣고 로그인한다.

토큰은 이 브라우저의 localStorage에 인스턴스별로 저장된다. 요청마다 `Authorization: Bearer <토큰>`, `X-Actor: owner`, `X-Session-Id: web-<브라우저마다 한 번 만든 값>`, `X-Client-Host: web` 헤더를 보낸다. 서버가 401을 돌려주면 그 인스턴스의 토큰을 지우고 로그인 화면으로 돌아간다. 사이드바의 로그아웃도 토큰을 지운다.

## 인스턴스와 프로젝트 전환

사이드바 맨 위(agent-board 이름)를 누르면 인스턴스를 바꾼다. 인스턴스마다 토큰과 선택한 프로젝트를 따로 기억한다. 그 아래 프로젝트 메뉴에서 전체 프로젝트나 프로젝트 하나를 고르고, 새 프로젝트 만들기, 이름·상태 수정, 삭제(확인 대화상자)를 한다.

## 마일스톤

사이드바의 마일스톤(`/milestones`, 단축키 `5`)은 고른 프로젝트의 마일스톤을 서버가 정한 목표일 순(목표일이 없는 것은 뒤)으로 보여 준다. 프로젝트를 고르지 않았으면 안내만 나온다.

- 오른쪽 위에서 열림(기본), 닫힘, 전체를 전환한다. 전체는 삭제된 마일스톤까지 보여 준다. 선택은 주소의 `status`(`closed`, `all`)에 담긴다.
- 행마다 이름, 상태, 설명 한 줄, 목표일, 진행 막대를 보인다. 진행 문구는 `완료/대상 · 퍼센트`이고, 대상은 취소·삭제한 이슈를 뺀 이슈 수다. 대상이 없으면 `이슈 없음`이다. 퍼센트는 반올림하되 모두 끝나기 전에는 100%로, 하나라도 끝났으면 0%로 보이지 않는다. 진행 수나 상태가 바뀐 행은 갱신 때 잠깐 강조한다.
- 행을 누르면 그 마일스톤으로 거른 이슈 목록(`/issues?milestone=<ID>`)으로 이동한다. 이슈 목록의 기본 범위가 열린 이슈이므로 완료한 이슈는 상태 필터를 전체로 바꿔야 보인다.
- 새 마일스톤은 오른쪽 위 버튼으로 만든다. 행 오른쪽 끝 메뉴에서 이름·설명·목표일 수정, 닫기와 다시 열기, 삭제(확인 대화상자)를 한다. 삭제는 소프트 삭제라 이슈에는 마일스톤 이름이 계속 보이고, 삭제된 행에는 메뉴가 없다.
- 이슈 상세의 속성(주제 다음)과 새 이슈 대화상자에서 열린 마일스톤 중 하나를 고르거나 없음을 고른다. 이슈 목록의 필터 줄에는 주제 다음에 마일스톤 필터(마일스톤 없음 포함)가 있고, 프로젝트를 고른 상태에서만 보인다. 이슈 행에는 마일스톤을 보이지 않는다.
- 이슈 상세의 활동 기록에서 마일스톤 변경은 이름으로 보인다. 현황과 활동 화면에서는 이름을 찾지 않아 `마일스톤 #ID`로 보인다.

## 단축키

입력 칸이나 편집 가능한 요소에 포커스가 있거나 Ctrl/Alt/Meta가 눌려 있거나 이슈 패널이 열려 있으면 동작하지 않는다. 다른 단축키는 없다.

| 키 | 이동 |
|---|---|
| `1` | 현황 |
| `2` | 보드 |
| `3` | 이슈 |
| `4` | 활동 |
| `5` | 마일스톤 |

## 동작 메모

- 모든 조회는 3초마다 다시 불러오고, 새로 생기거나 `updated_at`이 바뀐 이슈와 새 활동을 잠깐 강조한다.
- 이슈를 누르면 보던 화면 위에 오른쪽 패널로 열리고 주소가 `/issues/<키>`로 바뀐다. 아래 화면은 그대로 남아 계속 갱신된다. 패널 안에서 상위·선행 이슈를 누르면 같은 패널의 내용이 바뀐다. 입력 칸 밖의 Esc, 바깥 클릭, 닫기 버튼, 브라우저 뒤로 가기로 닫으면 열기 전 화면으로 돌아간다. 주소로 바로 들어오면 이슈 목록 위에 열리고, 닫으면 이슈 목록으로 간다.
- 보드에서 카드를 끌어 열을 바꾸면 `PATCH`에 `If-Match: "<version>"`을 보낸다. 그 사이에 바뀌었으면(412) 알리고 다시 불러온다. 이슈 상세의 수정도 같다.
- 이슈 본문과 댓글의 마크다운은 원시 HTML을 글자로 보여 주고 `javascript:` 같은 주소를 비우며, 외부 링크에는 `rel="noopener noreferrer"`를 붙인다. CDN 스크립트는 쓰지 않고 폰트(Pretendard)도 npm 패키지로 싣는다.
- 시각은 모두 KST로 표시한다.
